**Course:** Web Development Laboratory (316U01L306)  
**Department:** Computer Engineering, K. J. Somaiya School of Engineering  
**Experiment:** Version Control System using Git & GitHub (Experiment 3)

---

## Project Overview
This web application provides real-time meteorological tracking, heat index hazard calculation, heatwave severity categorization, and essential public health safety advisories during severe temperature surges.

## Files Included
- `index.html`: Structure and content for the Heatwave Monitoring dashboard, severity table, calculator, and emergency contacts.
- `style.css`: Modern responsive stylesheet featuring alert themes and card-based grid layouts.
- `script.js`: Interactive JavaScript for dynamic heat index calculation and timestamp rendering.

## How to run locally
Simply open `index.html` in any modern web browser.
